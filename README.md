# 多寶塔 · 다보탑 해체 기록

경주 불국사 다보탑(국보, 통일신라 751년, 높이 10.29 m)을 **25종 69점의 석재 부재**로 절차적 복원한 뒤,
실제 해체 순서대로 상륜부 → 탑신부 → 기단부를 위에서부터 들어 올려 번호를 매겨 적치하고,
분해도를 거쳐 다시 조립하는 약 85초 분량의 영상과 인터랙티브 3D 뷰어입니다.

두 가지 에디션으로 렌더링합니다.

| 에디션 | 내용 |
| --- | --- |
| **정밀 석재** (`stone`) | 부재별 실측 비례의 기하 + 절차적 화강암 셰이더(운모·장석 반점, 얼룩, 빗물 자국, 지면 가까이 짙어지는 지의류). 부재가 떠난 자리에는 청사진 윤곽선이 남습니다. |
| **브릭** (`brick`, 레고 스타일) | 같은 기하를 **정확히 1:10 축척**(1 스터드 = 8 cm, 1 플레이트 = 3.2 cm)의 격자로 복셀화한 뒤, 표준 브릭(2×8 … 1×1)과 플레이트로 탐욕 병합. 브릭 12,902개 · 스터드 31,776개. 실제로 조립하면 높이 1.03 m. |

## 결과물

- `video/dabotap_stone.mp4`, `video/dabotap_brick.mp4` — 1920×1080, 30 fps, 84.6초, H.264 + 합성 사운드트랙
  (저장소 용량 때문에 CRF 17 마스터를 다시 인코딩한 약 40 MB 판본; 마스터는 `npm run render:*`로 다시 만들 수 있습니다)
- `dist/dabotap.html` — 파일 하나로 열리는 인터랙티브 뷰어 (three.js 포함, 오프라인 동작; 글꼴만 Google Fonts)
  - 재생/일시정지, 타임라인 스크럽, 0.5×/1×/2×, 정밀 석재 ↔ 브릭 전환, 자동/자유 카메라(드래그로 궤도 회전)
  - 단축키: `Space` 재생, `←/→` 2초 이동

## 영상 구성

1. **서막** — 탑 전경, 제목
2. **PHASE I 상륜부** — 찰주를 뽑아 올리며 보주·보개·보륜·앙화·복발·노반·연화좌
3. **PHASE II 탑신부** — 8각 옥개석, 주두형 받침, 16엽 연화석, 죽절형 석주, 8각 난간·갑석·신부, 사각 난간, 1층 갑석, 교차 받침, 방형석주
4. **PHASE III 기단부** — 돌사자(망실된 3구는 점선 윤곽으로 표시), 굄돌, 기단 갑석, 보계, 면석, 적심, 지대석
5. **적치장** — 부재가 나선형 적치장에 번호 순으로 놓인 모습을 수직 부감으로
6. **분해도** — 모든 부재가 축을 맞춰 떠오른 분해도, 부재명·한자 라벨
7. **재조립** — 다시 한 탑으로

각 부재가 들릴 때 화면에 부재 번호(DB-01…25), 이름·한자·영문, 설명, 규격(W×D×H), 체적, 중량(화강암 2.65 t/m³),
브릭 에디션에서는 브릭·스터드 수가 표시됩니다.

## 직접 실행 / 렌더링

```bash
npm install
pip install imageio-ffmpeg numpy        # ffmpeg 바이너리 + 사운드 합성

npm run build                           # dist/dabotap.html 생성
npx http-server web                     # 개발용 (three.js는 CDN import map)

node render/render.mjs --mode stone --stills 5,20,40,75   # 확인용 스틸
npm run render:stone                    # 영상 + 사운드 → video/dabotap_stone.mp4
npm run render:brick
```

GPU 없는 4코어 컨테이너 기준으로 석재판 약 70분, 브릭판 약 2시간 15분이 걸렸습니다(SwiftShader 소프트웨어 렌더링).

렌더러는 `web/`을 로컬로 서빙하고 헤드리스 Chromium에서 `window.DABO.seek(t)`로 프레임을 하나씩 정확히 그린 뒤
PNG를 ffmpeg로 바로 넘깁니다. 모든 움직임이 시간 t의 순수 함수라 어느 프레임이든 같은 결과가 나오고,
구간을 나눠 여러 브라우저로 병렬 렌더링한 뒤 무손실로 이어 붙입니다(`render/parallel.mjs`).
사운드(`render/audio.py`)는 같은 타임라인에서 합성합니다 — 시작과 끝의 범종(두 저음 부분음의 미세한 차로 맥놀이),
단계마다 작은 종, 부재가 들리고 놓일 때의 소리(석재: 마찰음·둔탁음, 브릭: 플라스틱 클릭)를 중량에 비례해 배치합니다.

## 코드 구성

| 파일 | 역할 |
| --- | --- |
| `web/src/parts.js` | 25종 69점 부재 카탈로그와 기하 (해체 순서) |
| `web/src/geom.js` | 닫힌 메시 원시 도형 (n각 절두체, 선반체, 8각 옥개석 곡면 등) |
| `web/src/lego.js` | 광선 패리티 복셀화, 브릭 탐욕 병합, 인스턴싱 |
| `web/src/materials.js` | 화강암·브릭(이음매)·지면 셰이더 |
| `web/src/choreo.js` | 적치장 배치(아르키메데스 나선), 궤적, 분해도, 카메라 경로 |
| `web/src/hud.js` | 자막·부재 대장·지시선·라벨·타임라인 |
| `render/` | 프레임 렌더러, 병렬 렌더러, 사운드 합성 |
